# 只保留官方画风，删除简约几何画风

ADR 0006 引入官方美术时把简约几何画风保留为 Art Style 的另一选项，理由是它更轻。实际使用后，官方美术好看得多，按需渲染下的资源开销也不大；而两套画法让每个新对象类型、每个新效果（例如动作动画）都要写两遍、测两遍。我们删除几何画风与画风设置，Room View 只用官方画风。几何画法只留作官方画法无法覆盖时的兜底：没有官方画法的赛季对象、赛季贴图取不到时的赛季对象、未知对象类型的占位。

## Considered Options

- **保留两种画风**：给低端设备留一个更轻的选项，但维护成本翻倍，且用户不再使用。

## Consequences

- 取代 ADR 0006 “简约几何画风保留为 Art Style 的另一选项”一条；0006 的其余决定（官方资源以贴图进入我们的 Scene、不嵌入官方渲染器）不变。
- 回归保护改为锁住录制房间在官方画风下的 Scene 快照。
- 本地已存的画风设置与导入文件中的该字段被忽略。
